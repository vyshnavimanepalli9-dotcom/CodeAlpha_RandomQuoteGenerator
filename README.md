# ✨ Random Quote Generator

A responsive Random Quote Generator developed as part of my CodeAlpha App Development Internship.

## 🚀 Features

- 🎲 Generate random quotes
- ✍️ Display quote author
- 📋 Copy quotes to clipboard
- ❤️ Add quotes to favorites
- 🗑️ Remove favorite quotes
- 💾 Save favorites using Local Storage
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click **New Quote** to generate a new quote.
